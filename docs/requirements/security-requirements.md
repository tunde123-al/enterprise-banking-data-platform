# Security and compliance requirements

| ID | Requirement |
| --- | --- |
| SR-01 | Authenticate users and workloads through Microsoft Entra ID. |
| SR-02 | Use managed identities/service principals with least privilege; use Key Vault for exceptional secrets. |
| SR-03 | Encrypt data in transit and at rest using platform controls. |
| SR-04 | Restrict data services through private endpoints/network rules where feasible. |
| SR-05 | Apply role-based access, masked views/aggregates, and Power BI RLS where customer detail warrants it. |
| SR-06 | Retain pipeline, access and data-quality audit evidence appropriate to the synthetic project. |
| SR-07 | Classify all simulated personal/financial fields as synthetic confidential and prevent production-data import. |

The design is GDPR-aware but is not certification or legal advice. Production compliance requires legal, privacy, risk, security and regulator review.
